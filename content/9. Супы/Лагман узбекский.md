### Инвентарь

Кастрюля с покрытием (2 шт)

### Ингредиенты

|      Продукт       |    Количество    | Производитель |
| :----------------: | :--------------: | :-----------: |
| Говядина (лопатка) |      1,5 кг      |               |
|        Лук         |       1 шт       |               |
|      Мокровка      |      2 шт.       |               |
|      Картошка      |      1-2 шт      |               |
|      Спагетти      |      0,5 кг      |               |
|   Томатная паста   |  2 чайные ложки  |               |
|  Соль/перец/зира   |     По вкусу     |               |
|  Сливочное масло   | 2 столовые ложки |               |

### Способ приготовления (лагман)

- Нарезаем мясо маленькими кусочками размером с 1,5-2 фаланги пальца;
- Чистим лук, морковь, картошку;
- Лук нарезаем полукольцами, картофель и морковь кубиками;
- Растапливаем масло в кастрюле и кладем мясо;
- Слегка обжариваем мясо, 2-3 перемешиваем;
- Засыпаем лук, перемешиваем. Даем пожарится 2-3 минуты;
- Засыпаем морковь, перемешиваем;
- Залить водой, желательно кипяченой так чтобы вода закрыла с небольшим запасом всё мясо;
- Добавляем перец (1-2 чайные ложки) и зиру (1 чайная ложка);
- Варим в течение 1 часа. По прошествии часа проверяем готовность мяса. Если мясо жесткое, варим еще минут 15;
- Если мясо мягкое, добавляем томатную пасту солим и засыпаем картошку, перемешиваем и варим еще 15 минут на медленном огне.

### Способ приготовления (лапша)

- Заливаем воду в кастрюлю и ставим на плиту;
- После того как вода закипит, разламываем спагетти на три части и засыпаем в воду, варим 5-7 минут;
- По готовности наливаем немного растительного масла, чтобы макароны не приклеились к кастрюле;
- Сливаем воду, убираем макароны в отдельную тару.

### Подача

- В глубокую тарелку выкладываем спагетти и заливаем бульоном с мясом и картошкой.
