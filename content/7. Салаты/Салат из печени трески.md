### Ингредиенты

|    Продукт    | Количество |                Производитель                 |
| :-----------: | :--------: | :------------------------------------------: |
| Печень трески |  1 банка   |                                              |
|     Яйцо      |    6 шт    | Вараксино или Окское СО (отборная категория) |
| Репчатый лук  | 1 головка  |                                              |
|   Петрушка    |  по вкусу  |                                              |
|  Зеленый лук  |  по вкусу  |                                              |

### Способ приготовления

- Сварить яйца вкрутую;
- Мелко нарезать лук и зелень;
- Размять печень и яйца вилкой как модно мельче;
- Смешать все ингредиенты и подавать.
