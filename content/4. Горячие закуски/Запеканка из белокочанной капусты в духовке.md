# Вариант 1

## Ингредиенты

|   **Продукт**    | **Количество** | **Производитель** |
| :--------------: | :------------: | :---------------: |
|     капуста      |    0, 5 кг     |                   |
|      молоко      |     0,5 л      |                   |
|       яйца       |      2 шт      |                   |
|       сыр        |     100 г      |                   |
| специи /приправы |    по вкусу    |                   |

## Способ приготовления

- Капусту порезать, переложить в сковороду, подсолить, залить молоком, тушить мин 5-6, накрыв крышкой
- Остудить, добавить специи, выложить в глубокую форму, посыпать тертым сыром, залить хорошо взбитыми яйцами
- Запекать около 30 мин при температуре 180-190 градусов

К капусте можно добавить обжаренный лук и морковь

## Способ приготовления

- подготовить овощи
- лук,  пожарить до золотистого цвета, добавить морковь
- добавить фарш, соль, перец, перемешать, жаить мин 20
- выложить в форму половинц капусты, промазать сметаной, фарш, капусту, сметану
- посыпать сыром
- выпекать мин 30 при температуро 170-180 гр
