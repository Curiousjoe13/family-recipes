# Инвентарь

- Скоровода с высокими бортами
- маленькая сковородка диаметром около 15 см

# Ингредиенты

|      **Продукт**       |  **Количество**  | **Производитель** |
| :--------------------: | :--------------: | :---------------: |
| Грибы белые шампиньоны |       1 кг       |                   |
|    Сливочное масло     | 4 столовые ложки |    Вкуснотеево    |
|     Сметана (30%)      |      300 г       |     President     |
|          Лук           |       2 шт       |                   |
|          Мука          | 2 столовые ложки |       Макфа       |
|      Сыр (тертый)      | 4 столовые ложки |                   |
|      Соль, перец       |     По вкусу     |                   |
|   Растительное масло   | 2 столовые ложки |      Altero       |

# Процесс приготовления

- Подготовленные грибы нарезать соломкой;
- Нагреть сковороду, добавить растительное масло;
- Мелко нарезать лук, обжарить до золотистого состояния;
- Выложить нарезанные грибы в сковороду;
- Когда выделенный грибами сок наполовину упарится, добавить сливочное масло, сметану, посолить и поперчить;
- Добавить к грибам лук, перемешать тщательно;
- Тушить 15 минут на среднем огне;
- Спассеровать1 пшеничную муку до золотисто-коричневого цвета и появления запаха орехов;
- Засыпать спасерованную муку в грибы, перемешать;
- Тушим еще 3-5 минут. Если жульен получается густым можно добавить еще кипятка (100-150 мл);
- Выложить в форму, посыпать тертым сыром, запечь в духовке до появления румяной корочки.

> [!NOTE] ПРИМЕЧАНИЕ
> Пассерование - обжаривание муки на сухой сковороде (без добавления масла), при постоянном помешивании до золотисто-коричневого цвета и появления запаха орехов.
