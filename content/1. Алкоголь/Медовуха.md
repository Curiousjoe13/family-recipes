# Ингредиенты

|           **Продукт**            |  **Количество**  | **Производитель** |
| :------------------------------: | :--------------: | :---------------: |
|               мед                |      150 гр      |                   |
|               вода               |      1 литр      |                   |
|              дрожжи              | 1/2 чайной ложки |                   |
|              хмель               |      2,5 гр      |                   |
| корица, мускатный орех, кардамон |                  |                   |

# Способ приготовления

- воду вскипятить, добавить мед
- варить все время помешивая, чтобы мед не пригорел ко дну
- пенку снимать, иначе медовуха получится мутной
- добавить хмель и специи
- остудить до 30 градусов, добавить дрожжи
- оставить в теплом месте
- через пару дней на поверхности появится пенка
- перелить в 3-х литровые банки, добавить по 3-5 шт изюма для брожения, надеть перчатку, проколоть иглой дырочку
- перчатки должны надуться и подняться
- когда начнут опадать, перелить медовуху в бутылки, поставить в прохладное место для осветления
- периодически стравливать газ из бутылок
