# Инвентарь

- Сковородки для блинов

# Ингредиенты (2 нормы)

|                       |                    |               |
| --------------------- | ------------------ | ------------- |
| Продукт               | Количество         | Производитель |
| Молоко                | 400 мл             |               |
| Сахар                 | 6 столовых ложек   |               |
| Мука                  | 2 стакана          |               |
| Соль                  | 2 щепотки          |               |
| Разрыхлитель для муки | 2 пакетика         | Dr.Oetker     |
| Яйца                  | 4 шт               |               |
| Растительное масло    | 4-5 столовые ложки |               |

# Способ приготовления

- Сахар, молоко, соль, яйца взбить миксером
- Добавить муку, смешанную с разрыхлителем
- Перемешать до состояния густой сметаны, без комочков

> [!NOTE] ПРИМЕЧАНИЕ
> Режим плиты - 5
