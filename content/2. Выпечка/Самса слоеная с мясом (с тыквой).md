# Ингредиенты для теста

| Продукт                     | Количество        | Производитель |
| --------------------------- | ----------------- | ------------- |
| Вода теплая                 | 1 стакан          |               |
| Сметана 15-20%              | 1 стакан          |               |
| Мука                        | 4 стакана         | Макфа         |
| Соль                        | Щепотка           |               |
| Маргарин                    | 2 пачки по 200 гр | Хозяюшка      |
| Желток для смазывания теста | 2-3 шт            |               |

# Способ приготовления теста

- В эмалированной миске смешать воду и сметану, добавить соль;
- Просеять 4 стакана муки в миску;
- Замесить мягкое тесто;
- Раскатать толщиной в 1-1,5 см;
- Натереть на терке по всей поверхности теста сильно замороженный маргарин (1 пачку);
- Сложить тесто вчетверо вдоль пласта, раскатать;
- Натереть вторую пачку маргарина;
- Сложить вчетверо вдоль пласта, раскатать;
- Свернуть раскатанное тесто рулетом;
- Накрыть пленкой и поставить в холодильник (можно на сутки-двое);

|           Курдючное сало            |    50-70 г     |               |

# Способ приготовления фарша

Мясо, лук и курдючное сало пропустить через крупную сетку мясорубки. Перемешать с добавлением соли, перца, зиры и кориандра.

# Способ приготовления самсы:

- От рулета из теста отрезать кусочек толщиной около 1 см
- Слегка раскатать
- В серединку положить фарш
- Сложить тесто треугольником, защипнув верхний уголок
- Выложить на противень, застеленные бумагой для выпечки обратной стороной вниз
- Смазать самсу желтком и посыпать черным тмином или калинджи
- Поставить выпекать при температуре 250-300 градусов, верх-низ в течение 25-30 минут до зарумянивания.
