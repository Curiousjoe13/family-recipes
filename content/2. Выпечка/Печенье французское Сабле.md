# Ингредиенты

|        Продукты        |    Количество    |                Производитель                 |
| :--------------------: | :--------------: | :------------------------------------------: |
|          Мука          |    3 стакана     |                    Макфа                     |
|         Сахар          |     1 стакан     |                                              |
|    Сливочное масло     |      300 гр      |                                              |
|         Желтки         |       4 шт       | Вараксино или Окское СО (отборная категория) |
| Разрыхлитель для теста | 0,5 чайной ложки |                                              |

# Способ приготовления

- Желтки взбить с сахаром до светлой пушистой массы;
- Добавить мягкое сливочное масло, еще раз взбить;
- Сыпать просеянную муку с разрыхлителем и быстро замесить легкое тесто. Долго вымешивать такое тесто не нужно;
- Раскатать тесто между двух листов пергамента )толщиной 2-3 мм) и поместить в холодильник минимум на полчаса;
- Из охлажденного теста сформировать печенья и выпекать в разогретой до 150-160 С духовке 15-20 минут до золотисто-румяного цвета.
